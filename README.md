Dashboard Unimed - Diárias Hospitalares 🏥
📋 Sobre o Projeto
Dashboard interativo para análise de diárias hospitalares com classificação LOCAL/INTERCÂMBIO, desenvolvido para a Unimed. A aplicação permite visualizar, filtrar e analisar dados de internações hospitalares com interface moderna e intuitiva.

✨ Funcionalidades
🔐 Segurança
Autenticação por senha corporativa

Sessão com tempo limite (8 horas)

Acesso restrito à equipe autorizada

📊 Análises Disponíveis
Métricas Principais: Pacientes únicos, valor total, distribuição local/intercâmbio

Evolução Temporal: Análise por competência (mês/ano)

Ranking de Prestadores: Top 10 por valor e quantidade

Análise por Procedimento: Distribuição por tipo de diária

Distribuição Geográfica: Análise por município

🔧 Recursos Avançados
Filtros Dinâmicos: Competência, tipo, município, prestador, procedimento

Tema Dark/Light: Interface adaptável

Exportação de Dados: CSV, Excel e relatórios executivos

Gráficos Interativos: Plotly com visualizações profissionais

Responsivo: Adaptado para diferentes dispositivos
